# Retail-Analytics-Executive-Dashboard
This project demonstrates how SQL and Power BI can be used to analyze retail transaction data and transform it into actionable business insights.

The dashboard focuses on customer behavior, product performance, and executive KPIs through an interactive three-page report.

# Objectives
• Analyze customer purchasing behavior
• Identify top-performing products
• Monitor key business KPIs
• Understand shopping trends
• Build an executive dashboard

# Key Insights 
• Peak shopping occurs between 10 AM and 2 PM.
• Around 69% of orders are placed on weekdays.
• Produce is the highest-performing department.
• Average basket size is approximately 10 products.
• Reorder rate indicates strong customer loyalty.
